# Md Sarwar Osman Sagar — Portfolio

Static site deployed on Vercel: https://sarwar-osman.vercel.app

All files live in the repository root (no subfolders). Upload or replace files directly at the top level.
Edit personal information in `profile.js`; site-wide design lives in `style.css`.

## Security and snapshot
`firestore.rules` holds the database rules, `vercel.json` the security headers, and `SECURITY-SETUP.md` the manual console steps. The home page "Work performance snapshot" (`snapshot.js`) reads one public summary document written only by the owner from AeroOps > Settings > Public snapshot. `vendor/` holds self-hosted copies of Chart.js 4.4.4 and SheetJS 0.18.5.
