Connect Live Cloud Sync

This uses a free Google Firebase project as your live database — no coding needed, takes about 5 minutes the first time. Once connected, every entry saves instantly and shows up on every device you connect with this same config.

  1. Go to console.firebase.google.com → Add project (any name, e.g. "my-work-records") → skip Google Analytics.
  2. In the project, open Firestore Database → Create database → pick a region → start in test mode.
  3. Open Authentication in the sidebar → Get started → click Email/Password → enable it → Save. This is what keeps your data private.
  4. Click the ⚙️ gear (Project settings) → under "Your apps" click the </> (Web) icon → register an app (any nickname) → it shows a firebaseConfig object.
  5. Copy that whole { ... } object and paste it below.
